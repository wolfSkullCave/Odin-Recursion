
# 🌀 Recursion Practice – The Odin Project

This repository contains my solutions and experiments for the **Recursion Project** from [The Odin Project](https://www.theodinproject.com/lessons/javascript-recursion).  
The goal is to strengthen understanding of recursion in JavaScript by solving classic problems and building reusable functions.

---

## 📚 Project Overview
Recursion is a fundamental programming concept where a function calls itself to solve smaller instances of a problem.  
This project explores:
- Breaking down problems into base cases and recursive cases
- Writing clean, maintainable recursive functions
- Comparing recursive solutions with iterative approaches

---

## 🛠️ Features
- Recursive implementations of common algorithms:
  - Factorial
  - Fibonacci sequence
  - Merge sort
  - String reversal
- Example test cases for each function
- Modular structure for easy extension

## 🚀 Getting Started

### Prerequisites
- Node.js installed (v16+ recommended)

### Installation
Clone the repository:
```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

Run the examples:
```bash
node recursion.js
```
